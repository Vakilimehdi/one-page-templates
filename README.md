## Customize in 5 minutes — سفارشی‌سازی در ۵ دقیقه

1. **Name** — search for the sample name (`Sarah Mitchell`, `James Kim`, `سارا احمدی`) and replace it everywhere.
2. **Photo** — replace the initials circle (marked `PHOTO` in the file) with `<img class="avatar-img" src="your-photo.jpg" alt="Your Name">`.
3. **Tagline** — edit the `.tagline` text under the name.
4. **Bio** — rewrite the paragraphs in the About section.
5. **Your work** — replace the sample essays / projects with your own (title, date, short description, link).
6. **Contact** — replace the email address and the social links.

Every editable spot is marked with an `EDIT:` comment in the full version.

## Deploy — انتشار

No build step — upload the single HTML file anywhere that serves static files. Rename it to `index.html` to serve it at the repo root, or drag it into Netlify, Vercel, Cloudflare Pages or any shared hosting.
